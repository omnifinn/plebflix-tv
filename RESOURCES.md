# Plebflix TV tape library

The channel JSON files in `channels/` are the source of truth. This page is generated by `npm run resources`. Do not edit it by hand.

Clips are archived for preservation and credited to their original creators — ask for removal any time. Each tape plays from a copy kept on plebflix.com, with the original YouTube, archive.org or Vimeo embed as a fallback. `original_url` is the original upload or site, or a Wayback snapshot when that page is gone. What counts as a classic is in `CLASSIC.md`. A Flash file plays only when its license allows Ruffle. Otherwise it stays off the loop.

A `pending` row was filed from the REC button. It is not in the live loop until someone confirms the embed, sets `duration` in seconds, and removes `"status": "pending"`.

## Filing a tape

Press REC on the deck, or edit `channels/suomi.json` / `channels/international.json` and open a pull request. The year has to be at least ten years ago, and at least three of the five signals in `CLASSIC.md` have to be honest. Run `npm run validate` and `npm run resources` before you push. `npm run verify-embeds` checks that YouTube ids still resolve and archive.org items still exist.

## Shelves

Places to look, and links the REC button will accept. A page from one of these shelves is not automatically a video. Playback still has to be an embed inside the set.

- [Internet Archive](https://archive.org/) — Video items and web captures. A details, embed, or download URL can play inside the set.
- [Wayback Machine](https://web.archive.org/) — Snapshots of pages that are gone. A filed snapshot is a lead until someone attaches a playable embed.
- [PANDORA](https://pandora.nla.gov.au/) — Australia's web archive. The overview says the collection is now in Trove.
  - [Overview](https://pandora.nla.gov.au/overview.html)
- [Trove](https://trove.nla.gov.au/) — National Library of Australia. PANDORA's captures are in the Australian Web Archive here.
  - [Website viewer](https://trove.nla.gov.au/website-viewer)
  - [Archived websites](https://trove.nla.gov.au/search/category/websites)
- [Australian Web Archive](https://webarchive.nla.gov.au/) — The webarchive host for Trove's archived websites.
- [WebCite](https://www.webcitation.org/) — The site still answers. The service itself is retired; the Wikipedia page says what it was.
  - [Wikipedia](https://en.wikipedia.org/wiki/WebCite)
- [Internet Memory Foundation](https://en.wikipedia.org/wiki/Internet_Memory_Foundation) — Defunct in 2018. The organisation's own site no longer resolves. Wikipedia, a Wayback snapshot, and the Arquivo.pt collection are the records.
  - [Wayback snapshot of the site](https://web.archive.org/web/20190104014745/http://internetmemory.org/en/)
  - [Collection at Arquivo.pt](https://arquivo.pt/InternetMemory/)
- [Arquivo.pt](https://arquivo.pt/InternetMemory/) — Portuguese web archive. It holds the Internet Memory Foundation collection.
- [Cyberfeminism Index](https://cyberfeminismindex.com/) — Mindy Seu's index of cyberfeminist sites, and the Inventory Press book.
  - [Inventory Press book](https://www.inventorypress.com/product/cyberfeminism-index)
- [Inventory Press](https://www.inventorypress.com/product/cyberfeminism-index) — Publisher page for the Cyberfeminism Index book.
- [CLIR](https://www.clir.org/) — Council on Library and Information Resources. The 1996 task-force report is the archiving document.
  - [Preserving Digital Information (Waters and Garrett, 1996)](https://www.clir.org/pubs/reports/pub63/)
  - [PDF](https://www.clir.org/wp-content/uploads/sites/6/pub63watersgarrett.pdf)
- [Preserving the Internet](https://www.scientificamerican.com/article/preserving-the-internet/) — Brewster Kahle, Scientific American, March 1997.
- [Archiving Websites](https://www.facetpublishing.co.uk/page/detail/archiving-websites/?k=9781856049009) — Adrian Brown, Facet Publishing, 2006 edition.
- [Personal Archiving](https://books.infotoday.com/Ebooks/379_Personal-Archiving-Preserving-Our-Digital-Heritage.htm) — Donald T. Hawkins, editor. Information Today, 2013.
- [Averting the Digital Dark Age](https://muse.jhu.edu/book/123276) — Ian Milligan, Johns Hopkins University Press, 2024. The MUSE page is the open-access copy.
  - [Author's books page](https://www.ianmilligan.ca/books/)
- [Wikipedia](https://en.wikipedia.org/wiki/Main_Page) — Articles on the clips, the memes, and the archives above.
  - [www.wikipedia.org](https://www.wikipedia.org/)
